# GG-Impute

Genotype imputation pipeline for downstream GWAS.

## Documentation

The full pipeline guide is published on GitHub Pages:

**https://bioinumer.github.io/GG-Impute/**

## Source

Documentation is written in Quarto (`README-Imputation.qmd`). To rebuild locally:

```bash
quarto render README-Imputation.qmd
cp README-Imputation.html docs/index.html
```
